# easy-tdx 模块全新 UI 设计方案 · 交付概览

**任务**：深入研究 easy-tdx Python 包功能 → 重新设计 FinFeed Web 中 easy-tdx 模块的全新用户界面（美观 + 易用 + 符合用户习惯）。

## 核心结论

1. **功能研究**：easy-tdx 提供行情/K线/分时/逐笔/板块/资金流/34 技术指标/缠论/回测（18 策略）/因子/公告财报/扩展市场等 60+ 能力，其中缠论与回测是差异化亮点。
2. **现状诊断**：现有页面是「API 功能表单」模式——以接口为中心、参数暴露过深、图表能力未释放、自选无持久化、状态卡占位。
3. **新设计**：重构为「个人投研工作台」——对象优先（全局标的 + 自选股）、任务组织（6 大场景导航）、图表优先（K线/缠论/回测可视化）、默认即用（参数折叠调优）、底部任务中心、红涨绿跌全程一致。
4. **实施成本低**：后端注册表 0 改动，前端按「场景 → group id」映射即可落地，文档第 9 节给出组件替换对照表。

## 关键决策

- 视觉延续 FinFeed tokens v3.0（Forest 品牌绿 #2f7d5b + 浅色主题 + 红涨绿跌）
- 缠论视图做成「结构图 + 8 项统计卡 + 买卖点信号列表」三合一
- 回测视图突出「数据评级徽章 S/A/B/C/D」这一 easy-tdx 特色能力
- 原型内置「设计说明」模式（紫色虚线标注设计决策点），便于评审

### 交互路径（对齐设计规格）

1. 顶部搜索或左侧自选股选标的 → 全局注入
2. 点击左侧场景或中部 Tab → 自动选择默认功能并执行（K线/缠论/回测等）
3. 右侧参数面板随功能联动、可折叠，默认值已调优
4. 底部任务中心实时显示执行进度，最近任务点击可回看结果

### 体验修复（2026-08-22 二轮）

- **执行入口收敛为一个**：删除 Hero 与卡片头部的重复执行按钮，仅保留右侧参数面板底部「执行」（折叠态有迷你 play 按钮兜底）；卡片头部改为任务状态徽章（执行中 x% / 已完成 / 失败）
- **执行后必有结果**：原总览视图下点执行/快捷任务后结果无载体显示。现快捷任务与最近任务回看都会自动定位到功能所属视图，结果面板立即可见；同时修复最近任务标签字段（func_label）显示为空的问题
