## 1. 研究结论：easy-tdx 是什么、能做什么

**easy-tdx** 是一个免费、开源、无需注册与 API Key 的通达信（TDX）协议直连 Python 包，毫秒级访问机构级行情。本项目（FinFeed）已将其中约 **60 项能力**封装为后端 REST 服务（`finfeed/integrations/easytdx/`），前端通过功能注册表（registry）动态渲染。

### 1.1 能力全景（六大领域）

| 领域 | 能力清单 |
|---|---|
| **行情数据** | K线（1/5/15/30/60分钟、日/周/月/季/年 + 前/后复权）、实时报价、五档、分时、逐笔成交、市场涨跌统计、涨跌停价计算 |
| **个股资料** | 财报三表（新浪）、最新财务快照（37 字段）、F10 公司信息、除权除息、公司公告（巨潮资讯，含 PDF 下载） |
| **市场扫描** | 板块列表/成分股/汇总/涨幅榜/N日涨幅榜（行业/概念/风格/地区）、资金流向（主力/超大/大/中/小）、集合竞价、异动监控、强势股排名 |
| **技术分析** | 34 个技术指标（MACD/KDJ/RSI/BOLL/DMI/ATR/捉妖大师/30日乖离率信号…）、**缠论分析**（K线合并→分型→笔→中枢→线段→买卖点→背驰，支持多级别联立） |
| **量化回测** | 18 个内置策略、组合回测、参数网格寻优、多因子、滑点/执行仿真、19 项绩效指标、**数据评级 S/A/B/C/D** |
| **系统能力** | 主机延迟探测、最优主机自动选择、服务器信息、离线数据同步（本地 .day 文件）、扩展市场（港股/美股/期货） |

### 1.2 目标用户与心智模型

- 个人投资者：想快速看「一只股票现在怎么样」→ K线、分时、资金、公告
- 技术分析爱好者：想看「这只票的缠论结构」→ 缠论视图
- 量化初学者：想「验证一个策略」→ 回测视图
- AI 开发者：需要「结构化数据喂给 Agent」→ 输出格式（JSON/CSV/表格）可导出

**关键洞察：用户想的是「贵州茅台怎么样」，而不是「调用 get_security_bars 接口」。UI 必须以任务为中心，而非以 API 为中心。**

## 2. 现状诊断（现有 EasyTdxView.vue 的问题）

当前实现是「功能表单」模式：左侧场景化导航选功能 → 中间参数表单 → 底部结果表格。

| # | 问题 | 影响 |
|---|---|---|
| 1 | **以 API 功能为中心**：导航按 `kline / minute / macboard / maccapital` 等协议分组 | 60+ 功能靠记忆与搜索，专业分组对普通用户无意义 |
| 2 | **参数暴露过深**：`market / code / category / start / bar_time` 等字段直接平铺 | 新手被专业字段淹没，不知道哪些是必填 |
| 3 | **结果区表格化**：K线/缠论/回测等强可视化能力仅渲染为表格 | 图表能力（ECharts）未被释放，洞察成本高 |
| 4 | **标的上下文割裂**：股票选择器是独立横幅，选完才注入参数 | 用户必须先理解"选择器→功能→参数"三层关系 |
| 5 | **快捷任务与功能列表割裂**：工作台卡片与全部功能页是两套界面 | 用户心智中功能是分散的 |
| 6 | **自选股无持久化**：每次进入都要重新输入代码 | 高频使用路径断裂 |
| 7 | **状态卡占位**：页面底部固定 240px 高度状态日志 | 挤占工作区，执行状态喧宾夺主 |

## 3. 设计目标与原则

**一句话定位**：把 easy-tdx 从「API 浏览器」重构成「个人投研工作台」。

1. **对象优先（Object-first）**：全局标的条 + 自选股，个股类操作零成本带上下文
2. **任务组织（Task-organized）**：六大场景（总览/K线行情/资金/缠论/回测/市场扫描）对应真实心智，60+ 功能收纳其中
3. **图表优先（Visual-first）**：凡能上图的一律上图——K线蜡烛、缠论笔段中枢、回测净值回撤、资金流向
4. **默认即用（Defaults matter）**：参数默认值已调优，高级字段折叠，不打断主流程
5. **持续监控（Task center）**：底部任务中心替代页内状态卡，执行进度、日志、最近任务一栏搞定
6. **红涨绿跌**：全程遵循 A 股惯例（涨 #e5484d / 跌 #12a150）

## 4. 信息架构（IA）

```
easy-tdx 投研终端
├── 顶部命令条 Command Bar
│   ├── Logo + 产品名
│   ├── 全局标的搜索（名称/代码/板块，Ctrl+K）
│   ├── 主机连接状态（延迟 + 在线指示）
│   └── 服务器时间
├── 左侧栏 Left Rail（236px）
│   ├── 自选股（持久化，点击即切换全局标的，可增删）
│   └── 功能场景导航（6 场景，含功能计数）
│       ├── 总览工作台（12）——快捷任务 + 当日资金 + 五档 + 所属板块
│       ├── K线 / 行情（8）——K线图、分时、逐笔、五档
│       ├── 资金流向（3）——当日分档、历史资金、异动
│       ├── 缠论分析（5）——结构图、笔段中枢、买卖点、多级别
│       ├── 策略回测（6）——回测、组合、参数寻优、评级
│       └── 市场扫描（9）——板块榜、强势股、异动、竞价
├── 中间工作区 Center
│   ├── 标的名片 Hero（现价/涨跌/量额/换手/市盈率 + 自选/刷新）
│   ├── 快捷任务条 Quick chips（高频操作一键直达）
│   ├── 视图 Tab（总览 | K线 | 分时 | 资金 | 缠论 | 回测 | 板块榜）
│   └── 视图内容 Viewport（图表优先，随参数联动）
├── 右侧参数面板 Param Panel（288px，可折叠）
│   └── 上下文相关参数（随视图联动，默认值调优，高级字段折叠）
└── 底部任务中心 Task Bar（46px）
    ├── 当前任务进度 + 状态 + 日志
    └── 最近任务 chips（一键重跑）
```

**信息流**：选标的（自选/搜索）→ 选场景（左栏）→ 选视图（Tab）→ 微调参数（右栏）→ 看结果（图表）→ 跑任务（底部监控）。

## 5. 视觉系统

### 5.1 色板（对齐 FinFeed tokens v3.0，浅色主题）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f6f8fa` | 页面底色 |
| `--surface` | `#ffffff` | 卡片/面板 |
| `--surface-2` | `#eef1f5` | 次级底（搜索框、seg） |
| `--border` | `#e3e8ef` | 常规描边 |
| `--border-strong` | `#cdd5e0` | 控件描边 |
| `--text-1 / 2 / 3` | `#121926 / #4b5565 / #9aa4b2` | 三级文字层级 |
| **`--brand`** | **`#2f7d5b`** | 品牌绿（主操作、激活态） |
| **`--up` 涨** | **`#e5484d`** | 红：上涨/买入/净流入 |
| **`--down` 跌** | **`#12a150`** | 绿：下跌/卖出/净流出 |
| `--warn` | `#f59e0b` | 警示/运行中 |

### 5.2 字体与数字

- 正文：Inter + PingFang SC / Microsoft YaHei（沿用项目字体栈）
- **数据数字统一等宽** `JetBrains Mono` + `tabular-nums`，保证列对齐、价格可扫读
- 字号刻度沿用项目 1.2 模块化刻度（11.5/13/14/15/19/30），关键价格 30px 加粗

### 5.3 间距 / 圆角 / 阴影 / 动效

- 间距：8px 基准栅格（8/12/14/16）
- 圆角：卡片 14px、控件 10px、pill 胶囊（快捷任务/徽章）
- 阴影：`0 1px 2px` 轻投影，hover 卡片 `0 4px 12px` 抬升
- 动效：150–180ms ease，仅用于 hover/focus/视图切换淡入，不干扰数据阅读

## 6. 组件规范

### 6.1 CommandBar（顶部命令条）
- 高度 56px，白色，底部 1px 描边
- 全局搜索：胶囊输入框，聚焦品牌绿光环（`box-shadow 0 0 0 3px rgba(47,125,91,.12)`），右侧 `Ctrl K` 快捷键提示
- 主机状态：双状态点（绿色脉冲=在线）+ 延迟数字（等宽），hover 提示「自动探测最低延迟主机」

### 6.2 Hero（标的名片）
- 三段落布局：名称（含市场徽章 SH/SZ）｜ 现价+涨跌（30px 大字，红涨绿跌）｜ 指标带（今开/最高/最低/量/额/换手/PE）
- 右侧操作：☆ 自选（ghost）+ 刷新（primary）
- 响应式：<1200px 折叠指标带

### 6.3 Quick chips（快捷任务条）
- 胶囊按钮，hover 品牌绿描边 + 轻微抬升
- 预置参数：如「日K蜡烛图」= 前复权日线 120 根，点击即跑
- 与总览页「快捷任务网格」为同一数据源，一次理解

### 6.4 自选股 Rail
- 每项：名称+代码｜现价｜涨跌幅（红绿），hover 出删除
- 激活项：品牌绿浅底 + 绿描边
- 底部虚线「＋ 添加」按钮
- 数据本地持久化（localStorage / 后端 API）

### 6.5 场景导航 Rail
- 图标块（36px 圆角方块）+ 场景名 + 功能计数
- 激活态：绿底白图标 + 品牌深绿文字
- 图标为线性风格，语义化（K线=柱状、资金=货币、缠论=波浪、回测=CPU、扫描=折线）

### 6.6 视图 Tab + 场景联动
- 顶部 Tab 与左侧场景双向联动（点场景跳对应视图）
- 激活 Tab：品牌绿 2px 下划线 + 深绿文字

### 6.7 Param Panel（右侧参数面板）
- 288px 可折叠（折叠后 42px 图标条）
- 上下文联动：切视图即切换参数组（K线/缠论/回测各有专属参数）
- 控件：统一 34px 高 select，聚焦品牌光环
- 底部「应用并刷新」主按钮 + 「默认值已调优」提示卡

### 6.8 Task Bar（底部任务中心）
- 46px 常驻，不遮挡工作区
- 运行态：spinner + 任务名 + 进度条（品牌绿渐变）+ 百分比
- 完成态：最近任务 chips（绿点=成功），点击重跑
- 日志区：等宽字体单行滚动

### 6.9 图表规范（ECharts）
- 红涨绿跌贯穿所有图表（K线蜡烛、成交量、资金条、回测净值）
- tooltip 深底白字（`#121926`），紧凑信息
- K线图：主图 + 成交量副图 + 指标线（MA 橙/紫/青），滑杆缩放
- 缠论图：笔连线（品牌绿半透明）、中枢矩形（紫色虚线）、买卖点三角标记（B 红 / S 绿，白描边）

## 7. 视图规格

### 7.1 总览工作台
- **快捷任务网格**（8 卡）：图标+标题+描述，点击即跑
- **当日资金流向**：分档净流入条形（主力/超大/大/中/小），红进绿出，对称中线
- **五档行情**：卖5→买5 条形，中间最新价
- **所属板块**：行业/概念/风格归属 + 板块涨跌 + 主力净流入

### 7.2 K线视图
- 主卡：蜡烛图 + MA5/10/20 叠加 + 成交量副图 + 数据缩放
- 指标 seg 切换：MA / MACD / KDJ / BOLL（后续可叠加副图指标）

### 7.3 分时视图
- 价格线（涨红/跌绿/平灰动态着色）+ 均价线 + 成交量
- 支持「今日 / 近5日 / 指定日期」

### 7.4 资金视图
- 左：历史资金流向 30 日柱状（红正绿负）
- 右：今日分档净流入明细

### 7.5 缠论视图 ⭐（easy-tdx 差异化能力）
- 左：缠论结构图——笔连线、中枢矩形（zg/zd 上下沿）、一类/二类/三类买卖点三角标记
- 右：结构摘要（原始K线/缠论K线/分型/笔/中枢/线段/买卖点/背驰 8 项统计卡）
- 右：买卖点信号列表（B/S 徽章 + 类型 + 描述 + 日期），点击可联动图表定位

### 7.6 回测视图 ⭐
- 顶部 KPI 行：**数据评级徽章**（S/A/B/C/D，大号彩色圆角块）+ 总收益/年化 + 最大回撤/夏普/胜率
- 主图：策略净值 vs 沪深300 基准（虚线）对比
- 交易明细表：日期/方向（买红卖绿徽章）/价格/数量/单笔盈亏

### 7.7 板块榜
- 行业/概念/风格 seg 切换
- 排行表：涨跌幅（红绿）、资金强度 mini bar、成交额、主力净流入、涨/跌家数

## 8. 可访问性（WCAG AA）

- **对比度**：正文 ≥ 4.5:1（text-2 #4b5565 在白色上 7.0:1）；涨跌色仅用于数据强调，不作唯一信息载体（同时显示 +/- 号）
- **键盘可达**：全部交互元素为原生 button/select，Tab 顺序从左到右自然流转
- **焦点可见**：`focus-visible` 品牌绿 2px outline
- **触控目标**：列表项/按钮 ≥ 36px，关键按钮 ≥ 40px
- **动效偏好**：尊重 `prefers-reduced-motion`，视图切换动画可关闭

## 9. 实施映射（与现有代码的对应关系）

新 UI 可直接在现有架构上落地，无需动后端：

| 新组件 | 对应/替换现有文件 | 说明 |
|---|---|---|
| CommandBar 全局搜索 | `EasyTdxStockPicker.vue`（复用）+ `EasyTdxView.vue` 头部 | 搜索逻辑复用 stockNames 数据 |
| 自选股 Rail | 新增 `EasyTdxWatchlist.vue` | 持久化可接后端 /api 或 localStorage |
| 场景导航 | `EasyTdxNav.vue` 改造 | 由「协议分组」改为「六大场景分组」，注册表 `registry.py` 的 `SCENES` 映射已在 view 层定义 |
| Hero 名片 | 新增 `EasyTdxHero.vue` | 数据源：`mac_stock_quotes` / `mac_symbol_info` |
| 快捷任务 | `EasyTdxQuickTasks.vue` 增强 | 保持 `run()` 事件协议 |
| K线视图 | `EasyTdxResultPanel.vue` 中 buildCandle 抽离为 `EasyTdxCandleChart.vue` | 增加 MA 叠加与指标切换 |
| 缠论视图 | 新增 `EasyTdxChanlunView.vue` | 后端 `chanlun_analyze` 返回笔/中枢/买卖点，前端可视化 |
| 回测视图 | `EasyTdxResultPanel.vue` equity 部分抽离 | 复用 `backtest_run` 结果 |
| 参数面板 | `EasyTdxParamForm.vue` / `EasyTdxParamPanel.vue` | 改为随视图联动的折叠面板 |
| 任务中心 | `EasyTdxTaskStatus.vue` + `useTaskRunner.js` 改造 | 从页内 240px 卡迁移到底部 46px 常驻栏 |

**功能注册表无需变更**：`registry.py` 的 `GROUPS` 仅是元数据，新导航只需在视图层建立「场景 → group id」映射（现有 `SCENES` 常量已是雏形），后端 0 改动。
