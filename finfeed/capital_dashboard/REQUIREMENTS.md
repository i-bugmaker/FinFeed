# 全市场资金流与板块轮动监控大屏 — 需求规格（V2）

> 本文件为模块的功能与体验规格基线，开发、评审、验收均以本文为准。
> 关联实现：`finfeed/capital_dashboard/`（后端 + `web/index.html` 大屏）。

## 0. 背景与目标
基于 `easy-tdx`（通达信 MAC 协议）实时抓取沪深两市资金流向数据，构建一套适配大屏（≥1920×1080）的可视化监控大屏，支持实时刷新、榜单排行、板块轮动识别。V2 在 V1 基础上新增**亮/暗双主题**与**字体清晰性**两类硬性体验要求。

## 1. 数据采集
- 数据源：`easy-tdx` 连接 TDX 行情服务器。
- 覆盖范围：沪深两市全市场个股与板块。
- 维度：主力资金净流入/流出，以及超大单、大单、中单、小单等拆分层级。
  - 口径说明：TDX 协议当日仅提供「主力（≈超大单+大单） / 散户（≈中单+小单）」两档；
    四档拆分以「当日两档 + 5 日大/中单净额」呈现，需在界面标注口径，避免歧义。
- 实时性：支持定时轮询（可配置间隔）+ 手动触发刷新。

## 2. 功能模块
- **全市场资金流总览**：按净流入、净流出排序，展示个股榜与板块榜。
- **板块轮动监控**：识别当日领涨/领跌板块，追踪板块间资金轮动趋势与切换信号。
- **实时刷新机制**：定时轮询（后台线程）+ 手动触发刷新接口（`/api/refresh`）。

## 3. 可视化大屏（核心展示）
组件清单：排行表格、资金流柱状图/热力图、板块轮动趋势图、涨跌统计、异动播报。
布局要求：大屏分辨率适配、信息分区清晰、重点数据突出。

## 4. 主题规范（亮 / 暗双主题）
- **双主题支持**：必须同时提供亮色（Light）与暗色（Dark）两套主题；大屏默认暗色，普通后台/嵌入页可亮色。
- **切换方式**：
  - 提供手动切换入口（顶栏主题按钮），切换为运行时生效，**不刷新页面、不丢失当前数据**；
  - 默认跟随系统 `prefers-color-scheme`，用户手动选择后记忆偏好（`localStorage`，键名 `capital_theme`）；
  - 未手动选择时，系统主题变更（OS 切换明暗）实时跟随。
- **配色与对比度**：
  - 暗色主背景建议 `#070b17`–`#0b1226` 区间，亮色主背景建议 `#eef2f8`–`#ffffff`；
  - **红涨绿跌**配色在两种主题下均须保证 ≥ WCAG AA 对比度（正文 4.5:1，关键数据 7:1）；
    亮色主题对红/绿做了加深处理（`#e03131` / `#0ca678`）以达标；
  - 图表（ECharts）配色须同步响应主题变量（`getPalette()`），避免图表与背景撞色；
  - 切换过程加入过渡动画（背景/边框 0.3s），避免硬切闪烁。
- **大屏观感**：暗色主题控制眩光，避免纯黑高亮块长时间盯盘疲劳；亮色主题避免强反光区域。

## 5. 字体清晰性规范
- **字体栈**：系统优先无衬线 + CJK 回退，保证跨平台清晰渲染：
  `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei",
   "Hiragino Sans GB", Roboto, "Helvetica Neue", Arial, "Noto Sans CJK SC", sans-serif`
- **数字对齐**：所有金额、涨跌幅、排名等数值使用 `font-variant-numeric: tabular-nums`（等宽数字），
  保证列对齐、便于盯盘比对；数值字体栈保留等宽/终端字体兜底。
- **字号阶梯**（最小可读 ≥ 14px，关键数据 ≥ 20px 且字重 ≥ 600）：
  | 层级 | 用途 | 字号 | 字重 |
  |---|---|---|---|
  | 主标题 | 品牌标题 | 24px | 700 |
  | 关键数据 | 指数值 / 成交额 / 主力净额 | 18–20px | 600 |
  | 区块标题 | 面板标题 | 14px | 600 |
  | 正文/表格 | 名称、表格单元 | 13–14px | 400–600 |
  | 辅助/轴标 | 坐标、标签、代码 | 9–12px | 400 |
- **可读性与对比**：正文与背景对比度 ≥ 4.5:1，关键数据 ≥ 7:1；正文字重 ≥ 400，
  禁止使用过细字重（< 400）的纯装饰字体；中文与数字混排不得错位、换行错乱。
- **大屏可读性**：1920×1080 及以上、常规观看距离下最小可读字号不低于 14px；
  禁止纯艺术字体用于数据区。

## 6. 技术实现
- 后端：Python（FastAPI）暴露 REST API，后台线程定时轮询 TDX。
- 前端：ECharts 渲染大屏；主题与字体通过 CSS 变量集中管理，切换时图表按 `getPalette()` 重绘。
- 交付：结构清晰、可直接运行的完整模块代码 + 使用说明（`README.md`）。

## 7. 验收标准（量化）
| 项 | 标准 |
|---|---|
| 双主题 | 亮/暗均可正常显示；切换无刷新、数据不丢；偏好被记忆（刷新页面仍生效） |
| 系统跟随 | 未手动选择时，跟随 OS 明暗切换 |
| 红涨绿跌 | 两主题下对比度均 ≥ AA（实测或取色验证） |
| 图表同步 | 主题切换后 ECharts 图表配色同步更新 |
| 字体 | 数值等宽对齐；关键数据字重 ≥ 600；最小主要字号 ≥ 14px |
| 对比度 | 正文 ≥ 4.5:1，关键数据 ≥ 7:1 |
| 适配 | 1920×1080 下无溢出、无横向滚动条、分区清晰 |

## 8. 实现记录（对照验收）
- 主题变量集中在 `:root` 与 `[data-theme="light"]`，页面/面板/表格/卡片背景全部引用语义变量。
- 首屏前内联脚本确定主题，避免闪烁；顶栏按钮切换并写入 `localStorage`；切换仅按新色板重绘图表（不重新请求）。
- `getPalette()` 按主题返回 ECharts 配色（涨跌、坐标、分割线、tooltip、折线序列、热力图区间）。
- 全局 `font-variant-numeric: tabular-nums` + 系统字体栈；字号按第 5 节阶梯设定。
